========================================
Quick Commands
========================================

Start Server:     node https-proxy.cjs
                  OR
                  start-https.bat

Stop Server:      Press Ctrl+C in terminal

Check Status:     netstat -an | findstr :8000

View Logs:        storage/logs/laravel.log

========================================
DNS Configuration Required
========================================

To access via https://centimet2.com:8000, add to hosts file:

Windows: C:\Windows\System32\drivers\etc\hosts
Linux/Mac: /etc/hosts

Add line:
127.0.0.1    centimet2.com

Network Access
========================================

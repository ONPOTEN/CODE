# Install Nodej:

Install nodejs using nvm.

# Backend laravel:
Run with command:
cd /home/dev/laravel-api
node https-proxy.cjs
Backend listen on port 8080,api listen on port 8000

# Backend socketio
Run with command:
cd /home/dev/server
npm run dev

# Frontend Nextjs
Run with command:
cd /home/dev/nextjs-frontend
npm run dev
